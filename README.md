# beth-dataset-anamoly-detection
This project is ran via the model_training.ipynb notebook located in the root folder. It uses the cleaned data sets located here: https://www.kaggle.com/datasets/katehighnam/beth-dataset?resource=download

HOW TO RUN:
1. From the root directory, pip install -r requirements.txt
2. Make sure you are running the notebook on python 3.14.2 (as that is what we are running on)
3. Follow the readme.md in /datasets/raw to get the needed data to run the project
4. Run the model_training.ipynb notebook in the root directory
